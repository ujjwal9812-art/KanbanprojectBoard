# Kanban Project Board

A drag-and-drop Kanban board for small teams. Built with HTML5, CSS3 and vanilla JavaScript.

**Live demo:** add your deployed link here

## Features
- Drag tasks between columns and reorder columns
- Due dates with overdue highlighting, plus Low / Medium / High priority
- Team members with avatars
- Search tasks and filter by member
- Progress bar and live stats
- Light and dark theme
- Undo after deleting a task or column
- Export, import and reset the board (JSON backup)
- Keyboard support: Enter to edit a card, Alt + Left/Right to move it between columns
- Accessible markup: skip link, labelled controls, visible focus, reduced-motion support
- Data saved in the browser with localStorage

## Run locally
Open `index.html` in any modern browser.
